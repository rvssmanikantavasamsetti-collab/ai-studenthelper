# StudyFlow AI

Build a complete hackathon MVP called "StudyFlow AI".

Create a responsive AI-powered student productivity web app.

Features:

1. Dashboard showing today's study plan, upcoming deadlines, pending/completed tasks, completion percentage and study hours.

2. Task Manager where users can add, edit, delete and complete tasks. Each task has subject, title, description, deadline, difficulty (Easy/Medium/Hard), estimated study hours and type (Assignment/Quiz/Exam/Project/Study).

3. Smart Priority Engine that calculates priority from deadline urgency, difficulty and estimated effort. Show High/Medium/Low priority and explain the reason.

4. AI Study Planner where users enter available study hours and receive a personalized study schedule based on their pending tasks and deadlines.

5. AI Quiz Generator where users enter a topic and number of questions, then receive MCQ practice questions, answers, explanations and a score.

6. Progress page showing completed tasks, pending tasks, completion percentage, study hours and subject-wise progress.

Use React and TypeScript with a modern professional UI. Make it responsive on desktop and mobile. Use local storage so the app works without a backend initially. Add realistic sample data. Make all main buttons and features functional. Create a polished hackathon-quality MVP, not just a static design.
